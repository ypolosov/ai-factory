# Фабрика ПО на ИИ для агента

Собрано из кода фабрики, версия источника 48de3911fc79. Правка - в источнике, не здесь.

## Подключение

У разработчиков подключён MCP фабрики (`http://127.0.0.1:4100/mcp`, ключ - `.state/coordinator/mcp.token`): BE - в Claude Code, FE - в Codex.

## Инструменты MCP фабрики

| Инструмент | Что даёт |
|---|---|
| `kb_search` | Поиск по знанию проекта - отрывки правил, решений (ADR) и описаний проекта со ссылками на источник в git. |
| `check_requirement` | Сверка требования со знанием проекта - сверщик фабрики: противоречит ли требование правилам и решениям проекта; с цитатами и ссылками. |
| `factory_rules` | Правила стражей фабрики - что проверит фабрика у любого изменения: правила для агентов цели, команды проверок и пределы стража. |
| `submit_task` | Передать задачу агенту фабрики - заводит задачу в трекере с меткой агента: фабрика сама отдаст её агенту и откроет PR. |

## Что делают люди в чате

Эти команды набирают люди в чате команды; агенту они нужны, чтобы понимать, откуда приходят задачи и решения.

- `!дейли` - что делает фабрика: задачи агентов, PR, решения, выкладка
- `!задача <название>. <описание>` - задача агенту фабрики
- `!выпуск` - что войдёт в следующий выпуск
- `!выкладка vX.Y.Z` - подтвердить выкладку выпуска на стенд
- `!учёт` - попытки, время и цена работы агентов по задачам
- `!правила` - сверщик ищет повторяющиеся замечания к PR и предлагает правило
- `!нарезка DRAW-N` - предложить задачи по стори; !утвердить DRAW-N [agent] - завести их
- `!e2e` - перезапустить сквозные проверки цели на стенде; итог - сюда же
- `!ci [номер PR]` - перезапустить CI цели (GitHub Actions) для PR или ветки по умолчанию
- `!судья N` - судья фабрики (Codex) снова смотрит PR N
- `!макет DRAW-N [ссылка на рамку Figma]` - сверить макет с задачей (или приложите картинку PNG)
