# Публикации: обзор готовых решений

Выбор владельца 15.10.2026: модель - LikeC4 без запасного формата; первый круг носителей схем - PlantUML и Miro, draw.io, Excalidraw и остальные - позже; тексты - как в разделе 3.

Стадия 2 РП публикаций, 15.10.2026. Источник - три исследования (модели и отрисовка с пробой кириллицы, доски, тексты); несущие факты перепроверены отдельно и помечены "проверено". Оценки часов - суждение по обзору, не замер.

## 1. Модель и отрисовка

| Кандидат | Одна модель - много видов | Экспорт | Лицензия, выпуск | Кириллица (проба) | Цена |
|---|---|---|---|---|---|
| LikeC4 | да; сценарии - динамические виды с вариантом sequence (только листовые элементы, есть параллельные шаги; проверено по документации) | PlantUML, Mermaid, D2, DOT, draw.io, JSON с координатами раскладки (у узла x, y, width, height - проверено) | MIT, 1.59.4 от 21.09 (проверено) | подписи любые, идентификаторы - латиница | образ 2 ГБ; PNG только через встроенный Chromium и под root |
| Structurizr | да | PlantUML, C4-PlantUML, Mermaid, JSON; PNG и SVG - образ с playwright | Apache-2.0 (проверено), 2026.09.19 | подписи работают | Java; облачные темы закрыты 30.09.2026 - строка `theme default` ломает экспорт |
| D2 | наружу только картинки | SVG, PNG, PDF | MPL-2.0 | курсив подписей связей без кириллицы, лечится `style.italic: false` | годится носителем |
| Mermaid | нет, C4 экспериментальный | картинки | MIT | норма | годится носителем |
| PlantUML + C4-PlantUML (сейчас) | нет, каждая схема отдельно | SVG, PNG, PDF | смешанные, C4-PlantUML MIT | в SVG подписи порезаны по словам ("База знаний" не находится одной строкой - проверено) | остаётся носителем |
| Kroki | нет, сервис отрисовки | что дают движки | MIT | кириллица числовыми сущностями | образ 4 ГБ, отстающие движки - не брать |

Рекомендация: модель - LikeC4; PlantUML остаётся носителем через `likec4 gen plantuml` и `make diagrams`. Запасной - Structurizr.

## 2. Доски

| Доска | Создание и обновление | Чтение обратно и черновик | Без браузера | Формат, лицензия |
|---|---|---|---|---|
| draw.io | LikeC4 экспортирует сам; id ячейки = id модели | разбор XML (сжатые страницы - `node:zlib`); свои атрибуты ячейки переживают копию -> копия узнаётся по метке модели | CLI в образе (Electron и xvfb) | файл в git, Apache-2.0 (проверено) |
| Miro | REST v2: фигуры, коннекторы, рамки; обновление по id, карту "модель -> id" держит фабрика; координаты - из JSON LikeC4 | элементы рамки и коннекторы; своих метаданных в REST нет -> ручную копию сопоставлять по тексту и положению, спорное - человеку | выгрузка картинок только в Enterprise (не нужна: картинки даёт LikeC4) | SaaS; лимит 100 000 кредитов в минуту, создание - 100, пакет до 20 элементов |
| Excalidraw | свой генератор из JSON LikeC4 | разбор JSON; `customData` копируется при дубликате | SVG только через Kroki | файл в git, MIT |
| tldraw | - | - | - | лицензия не OSI - не брать |

Черновик надёжнее, когда копию делает фабрика по команде "черновик" и записывает её в привязку; ручная копия распознаётся по правилам из таблицы.

Рекомендация: первый круг - PlantUML (текст), draw.io (файл в git, экспорт готов) и Miro (доска архитектора и канал предложений). Excalidraw - следующим кругом на том же контракте.

## 3. Тексты

- Руководство: Diataxis внутри роли, разделы только при наличии источника - справочник из OpenSpec и инструментов MCP, инструкции из сценариев, объяснения из ADR и модели, учебник "первый запуск".
- Агентам: AGENTS.md (постоянные правила, указатель на MCP фабрики) и навыки Agent Skills по ролям. Claude Code читает AGENTS.md сам, только если в проекте нет CLAUDE.md, иначе нужен импорт `@AGENTS.md` (с v2.1.277; проверено по документации). llms.txt - до публичного сайта не нужен.
- Confluence: порт вики фабрики уже переводит текст в формат хранения и обновляет страницу на месте через REST v1 - работает вживую (UC5). Расширить его: таблицы, картинки-вложения (v1), ссылки на элементы модели. Запасной путь - md2conf в образе (MIT).
- Слайды (РП презентаций): Marp в образе; Claude Design Slides - для витринной презентации вне сборки.
- Судья верности: без библиотек - текст -> утверждения -> вердикт по каждому с дословной цитатой; код проверяет, что цитата есть в источнике; порог - ноль неподтверждённых. Судья Codex у фабрики уже есть.
