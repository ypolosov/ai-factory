# Манифест публикаций фабрики (черновик)

Статус: состав принят владельцем 15.10.2026. Модель - LikeC4; первый круг носителей схем - PlantUML и Miro, остальные позже (выбор владельца 15.10.2026, [обзор](options.md)). Носители: руководство для людей - git и своё пространство Confluence фабрики; схемы на Miro - отдельная доска публикаций https://miro.com/app/board/uXjVEZCD9RI= (`make publications-miro`, карта элементов - [miro.json](miro.json)), доска целевой архитектуры владельца не перезаписывается (позже - канал предложений).

Каждая публикация - представление одного источника правды для названного читателя (FPF E.17): оно не добавляет утверждений, ведёт обратно к источнику и пересобирается при его изменении. Форма строк - как у точек зрения в [составах ролей](../compositions/README.md) (FPF E.17.0).

## Читатели

| Читатель | Кто | Что ему нужно |
|---|---|---|
| Роли команды | продукт, PM, архитектор, дизайнер, разработчики, QA, DevOps, эксплуатация, релиз | где и как делать свою работу через фабрику |
| ИИ-агенты людей | обвязки любого вендора (Claude Code, Codex, Cursor) | инструменты MCP фабрики, правила, порядок работы |
| Разработчики фабрики | владелец и разработчики ai-factory | устройство, порты, размещение |
| Внешние (РП 29) | инвестор-партнёр, B2B-команды 2-10 человек, солопренёры | предложение и ценность; источник о продукте - отдельно |

## Единое целое

- Одна модель: элемент описан один раз, все схемы и тексты берут его имя оттуда.
- Один стиль на всех носителях: цвет по виду элемента (человек, фабрика, внешняя система, цель), шрифт, одна легенда.
- Текст ссылается на элементы схем по имени модели.
- На каждом представлении - отметка версии источника.
