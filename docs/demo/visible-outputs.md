# Видимые выходы фабрики

Что фабрика показывает наружу и на что могут опираться другие системы. Главный потребитель сейчас - съёмка видео-демо ([ai-factory-film](https://github.com/ypolosov/ai-factory-film), `src/contract.ts`). Съёмка - отдельная система: ключей фабрики она не берёт и кода её не импортирует, поэтому знает о фабрике только этот перечень.

Каждый пункт проверяет контрактный тест [images/coordinator/test/visible-outputs.test.ts](../../images/coordinator/test/visible-outputs.test.ts). Как менять выход:

1. Поправить код, этот перечень и тест вместе.
2. Сказать потребителям: в ai-factory-film поправить `src/contract.ts` в том же выпуске.

Тест упадёт раньше, чем сломается дубль съёмки.

## Метки задач Jira

| Метка | Смысл |
|---|---|
| `story` | страница вики или задача - стори для сверки |
| `wiki-<id страницы>` | стори, заведённая фабрикой из страницы вики |
| `decision` | задача на решение по противоречию стори |
| `needs-decision` | стори ждёт решения |
| `story-ok` | стори согласована со знаниями проекта |
| `agent`, `agent:frontend`, `agent:backend` | отдать задачу агенту фабрики (роль агента) |
| `agent-running`, `agent-review` | агент работает, PR агента ждёт ревью |
| `agent-failed` | попытка агента не удалась |
| `design-ok`, `design-changes` | итог сверки макета |
| `incident` | баг сбоя стенда |
| `release-v<X.Y.Z>` | задача вошла в выпуск |

Задача, сделанная агентом, закрывается сама после слияния и выкладки. Закрытие - тоже видимый выход.

## Статусы коммитов в репозитории цели

`factory/verdict` (страж), `factory/judge` (судья), `factory/scan` (сканеры), `factory/deploy` (выкладка).

## Бот в Discord

- Ответ на команду приходит ответом на её сообщение, со ссылкой на него (message_reference).
- Сбой команды начинается с `Не вышло:`, `Не нашлось:` или `Фабрике не хватает доступа`.
- Временная недоступность площадки - ответ со словами `повторите команду`.
- Отказ в праве по реестру ролей начинается с `Нельзя `.
- Успешные ответы начинаются так:

| Команда | Начало ответа |
|---|---|
| упоминание бота (библиотекарь) | ответ содержит `Источники:` |
| `!нарезка` | `Сверщик предлагает нарезку ` |
| `!утвердить` | `Задачи заведены: ` |
| `!правила` | `Правило-кандидат предложено: ` и ссылка на PR |
| `!выпуск` | `## следующий выпуск: ` |
| `!выкладка vX.Y.Z` | `Выкладка vX.Y.Z подтверждена ` |
| `!дейли` | `Дейли фабрики:` |
| `!учёт` | `Учёт фабрики: ` |
| `!ci N` | `Перезапустил CI ` |
| `!e2e` | `Запустил e2e на стенде ` |

- Объявления (не ответы) несут идентификатор объекта:

| Событие | Объявление |
|---|---|
| итог перезапуска CI | `CI PR <N>, <задание>: ...` |
| итог e2e на стенде | `e2e на стенде (<короткий коммит>)...` |
| собран тег выпуска | `Собран тег v<X.Y.Z>...` |
| выпуск на стенде | `Выпуск v<X.Y.Z> на стенде...` и ссылка на заметки |
