# Test Plan

## Сквозные проверки

| Задача | Сценарий | Файл | Что проверяется |
|---|---|---|---|
| 1.2 | Приз не подтверждён в срок | e2e/tests/redraw.spec.ts | запрос повтора после срока - в ответе API новый победитель на том же месте |
| 1.2 | Срок подтверждения не истёк | e2e/tests/redraw.spec.ts | запрос повтора до срока - ответ 409, победитель прежний |

## Модульные тесты

Тесты исполнителя в `api/test/rules.test.ts` пишутся до кода: повтор берёт следующего кандидата, не выбирает уже выбранных, совпадает с пересчётом из зерна.

## Нефункциональные проверки

Ошибки повтора уходят в GlitchTip стенда, как и остальные ошибки API.
