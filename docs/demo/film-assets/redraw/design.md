# Design

## Context

Выбор победителей - чистая функция из зерна (ADR-3): на шаге i индекс из HMAC-SHA256(зерно, "pick:i") по модулю числа оставшихся. Уточнение ADR-3 ({decision.issue.key}): повтор продолжает эту последовательность.

## Goals / Non-Goals

**Goals:**
- Повтор, который любой пересчитает из опубликованного зерна.

**Non-Goals:**
- Новое зерно, экран повтора.

## Decisions

### Повтор - следующий шаг той же последовательности
- Контекст: R4 требует проверяемого выбора, R5 - не больше одного приза участнику.
- Решение: повтор места делает шаг i, где i - число уже сделанных выборов; кандидаты - участники без уже выбранных победителей.
- Рассмотренные альтернативы: новое зерно - ломает проверку R4; выбор среди всех - может снова выбрать не подтвердившего приз.
- Последствия: веб-приложение пересчитывает повтор тем же кодом выбора.

## Risks / Trade-offs

Кандидатов не осталось - повтор невозможен: API отвечает ошибкой 409.
