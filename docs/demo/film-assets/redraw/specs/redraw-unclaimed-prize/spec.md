# Spec Delta

## Purpose

Повтор невостребованного приза: новый победитель выбирается из той же последовательности кандидатов, что и исходные, и проверяется пересчётом из зерна розыгрыша.

## ADDED Requirements

### Requirement: Повтор продолжает последовательность из зерна
The system SHALL выбирать нового победителя невостребованного приза следующим шагом той же последовательности выбора из зерна розыгрыша среди участников, ещё не выбранных победителями.

#### Scenario: Приз не подтверждён в срок
- **WHEN** организатор запрашивает повтор приза победителя, который не подтвердил его за 3 дня
- **THEN** API отвечает новым победителем на этом месте - следующим кандидатом последовательности, а прежний победитель отмечен как не востребовавший приз

#### Scenario: Пересчёт повтора из зерна
- **WHEN** участник пересчитывает выбор по опубликованному зерну и списку участников
- **THEN** он получает тех же победителей, включая победителя повтора

### Requirement: Повтор только для невостребованного приза
The system SHALL отклонять повтор, если срок подтверждения приза не истёк или приз подтверждён.

#### Scenario: Срок подтверждения не истёк
- **WHEN** организатор запрашивает повтор раньше, чем через 3 дня после выбора победителей
- **THEN** API отвечает ошибкой 409 с причиной, победитель не меняется

#### Scenario: Приз подтверждён
- **WHEN** организатор запрашивает повтор подтверждённого приза
- **THEN** API отвечает ошибкой 409 с причиной, победитель не меняется
