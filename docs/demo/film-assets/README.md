# Заготовки сценария съёмки

Файлы, которые участники съёмки кладут в PR (`do.github.pr.files[].from` в [film.yml](../film.yml)) или прикладывают к реплике (`do.discord.file`). Строки `{шаг.поле}` режиссёр заменяет итогами прошлых шагов, `{шаг.поле|lower}` - строчными буквами.

- `redraw/` - изменение OpenSpec от Backend (ИИ) по задаче API повтора: замысел, требования со сценариями, решение, задачи, план проверки. Проверено `npm run spec:validate` цели.
- `redraw-screen.png` - макет экрана невостребованного приза, выгруженный из Figma: Designer (ИИ) прикладывает его к `!макет`. Сверка по ссылке Figma упирается в лимит API бесплатного плана (несколько запросов в месяц), картинка - нет.
