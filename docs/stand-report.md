# Отчёт стенда фабрики ПО на ИИ

11-12.10.2026, ноутбук (WSL2, 24 ГБ). Стенд - проверка сборки фабрики на представительной работе, а не продукт: hello world и todo list прошли путь от задачи до стенда через фабрику.

## Итог

Цикл "задача -> агент -> PR -> проверки -> ворота ИИ -> слияние -> стенд" работает без ручных шагов, кроме решения человека. Todo list (7 пунктов спецификации) собран агентами и выложен; 70% изменений слиты с первой попытки, у Codex по подписке - 80%. Изменение стоит в медиане 0,21 доллара и проходит путь от задачи до стенда за 17 минут; почти всё это время - проверки и ворота, а не работа модели (2 минуты). База знаний отвечает с цитатой решения и сама находит засеянные расхождения. Стек с базой знаний занимает около 10 ГиБ.

Данные - API Forgejo и журнал шлюза; задачи разработки обоих приложений (hello - ранние проверки цикла). У подписок цена теневая - по прайсу API вендора.

1. **Цена принятого изменения:** медиана 0,21 доллара; 10 слитых изменений стоили 3,86 доллара (агент 2,64, ворота и ревью 1,22). Дороже всего первые пункты todo на открытой модели (1,05 и 1,32): по пути чинилась сама фабрика.
2. **Время от задачи до стенда (медиана):** работа модели 2,3 мин, задача -> PR 2,5 мин, PR -> слияние 22 мин (проверки, мутационное тестирование до 7 мин, ворота, доработки), слияние -> стенд 0,5 мин; всего 17 мин.

Неудачи todo - проверка образа не состоялась: зеркало Google с базой уязвимостей отвечало стенду 403 (база теперь берётся из ghcr.io); у hello - битая версия при проверке отката. ## Что узнали

- **Узкое место - проверки и ворота, не модель.** Агент пишет пункт за 2-4 минуты; остальное - тесты, мутационное тестирование, судьи и доработки.
- **Ворота ИИ полезны.** Судьи другой модели вернули на доработку пропущенный тест из задачи и обновление зависимости вне задачи; середина шкалы уходит человеку.
- **Сбой внешней службы не должен выглядеть как ошибка кода.** Отказ osv.dev (403) толкнул агента "чинить" зависимости вне задачи. Теперь проверка зависимостей идёт по скачанной базе OSV, база Trivy - из ghcr.io.
- **Подписки вместо API.** Claude Code и Codex работают в заданиях по подпискам владельца через шлюз; токен подписки Claude в чужих программах Anthropic запрещает - для Onyx есть три законных пути (обёртка над `claude -p`, API-кредиты Max, OpenRouter).
- **Дневной бюджет и повторы.** Исчерпанный бюджет OpenCode повторял молча до тайм-аута; агент теперь проверяет бюджет сам.
- **Onyx - движок, а не решение.** Индекс, поиск и чат с цитатами готовы; коннектора Forgejo нет, документы из API загрузки он не ищет без своего коннектора, права по источникам - в платной части; сверка и типы знаний - свой слой.
- **Учёт с первого дня окупился:** без меток задач в шлюзе не было бы ни цены, ни сравнения исполнителей.
