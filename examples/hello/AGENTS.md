# Правила для агентов

- Node 24, ES-модули, без внешних зависимостей.
- Код - в `src/`, тесты - в `test/`, имя теста `<модуль>.test.js`.
- Сначала падающий тест, потом код. Проверка - `node --test` (так её запускают и проверки PR), должна проходить.
- Проверки PR, без которых main не слить: тесты, секреты (Gitleaks), уязвимые зависимости (OSV-Scanner),
  статический анализ (Opengrep, правила в `/etc/factory/checks`). Те же сканеры есть в рабочем окружении агента.
- Каталоги `.forgejo/` и `.github/` не менять.
- Сеть: из окружения агента наружу открыт только npm (через прокси фабрики); Forgejo и шлюз моделей - напрямую.
- HTTP-сервер приложения - `src/server.js`, порт из `PORT`, проверка здоровья `GET /health`: так его собирает и выкладывает фабрика.
