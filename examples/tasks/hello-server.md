Нужен HTTP-сервер приветствия в `src/server.js` на встроенном модуле `node:http`, без внешних зависимостей:

- экспорт `createServer()` возвращает сервер, не запуская его;
- `GET /` отвечает `Hello, world!`, `GET /?name=Ann` - `Hello, Ann!` (через `greet` из `src/greet.js`), тип `text/plain; charset=utf-8`;
- `GET /health` отвечает `200` и `ok`;
- другие пути - `404`;
- `node src/server.js` запускает сервер на порту из `PORT` (по умолчанию 8080) на адресе `0.0.0.0`.

Готово, когда `node --test` проходит, а тесты поднимают сервер на свободном порту и проверяют эти ответы.
