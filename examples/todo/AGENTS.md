# Правила для агентов

Todo list на Node 24 без внешних зависимостей: сервер на `node:http`, страница рисуется на сервере, данные в памяти процесса.

## Работа по фазам

Роли, их исполнители и разрешённые пути - в `.factory/config.yml`; чужие пути отклоняют ворота публикации.

- **spec** - изменение OpenSpec в `openspec/changes/<имя>/` по схеме `factory`: замысел, требования со сценариями, архитектурные решения, задачи, план проверки. Утверждает человек слиянием PR.
- **tests** - приёмочные тесты `tests/acceptance/<номер задачи>.test.js` по сценариям, до разработки.
- **dev** - одна задача из `tasks.md` - один PR. Приёмочные тесты задачи должны пройти.
- Ревью и слияние - проверки PR и человек.

Живые спецификации - `openspec/specs/`, изменения - `openspec/changes/`. CLI: `openspec list`, `openspec show <имя>`, `openspec validate <имя> --strict`.

## Код

- Код - в `src/`, модульные тесты - `test/<модуль>.test.js`; проверка - `node --test "test/**/*.test.js"`.
- Сервер - `src/server.js`: экспорт `createServer()`, порт из `PORT` (по умолчанию 8080), `GET /health` - 200 и `ok`. Так приложение собирает и выкладывает фабрика.
- Внешние зависимости не добавлять. Сеть наружу - только npm, через прокси фабрики.
