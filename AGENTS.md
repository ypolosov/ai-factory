# Правила для агентов в этом репозитории

- Компоненты - только под лицензиями OSI; версии образов и пакетов закреплять точным тегом. Исключение - CLI Claude Code:
  сменный исполнитель для подписки владельца; открытый исполнитель по умолчанию - OpenCode.
- Скрипты - POSIX sh; перед сохранением `make check` должен проходить.
- Службы и код фабрики на Node - TypeScript без сборки (Node 24 стирает типы) и без зависимостей для работы; перед сохранением `make test` должен проходить.
- Секреты, токены и пароли - только в `.state/` или `.env`; в git, в аргументы команд и в логи не попадают.
- Порты публикуются только на `127.0.0.1`.
- Контейнеры заданий не получают Docker API хоста или своего dind.
- В контейнеры монтировать каталоги, а не одиночные файлы: Docker Desktop теряет смонтированный файл после `sed -i` или `mv`.
- Ключи провайдеров знает только шлюз; исполнители получают ключ шлюза своей роли.
- Недоверенный код в заданиях (обвязки агентов, тесты из PR) запускать только через `factory-untrusted`.
- Новый адрес наружу для заданий - только строкой в `images/egress/allowlist.txt` с комментарием, зачем он нужен.
- Образы для Docker заданий собираются и скачиваются на хосте (`scripts/stand-up.sh`): сам Docker заданий в интернет не ходит.
