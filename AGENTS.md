# Правила для агентов в этом репозитории

- Компоненты - только под лицензиями OSI; версии образов и пакетов закреплять точным тегом.
- Скрипты - POSIX sh; перед сохранением `make check` должен проходить.
- Секреты, токены и пароли - только в `.state/` или `.env`; в git, в аргументы команд и в логи не попадают.
- Порты публикуются только на `127.0.0.1`.
- Контейнеры заданий не получают Docker API хоста или своего dind.
