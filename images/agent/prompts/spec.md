По задаче ниже создай изменение OpenSpec по схеме проекта (openspec/config.yaml):
1. Придумай короткое имя изменения в kebab-case и выполни `openspec new change <имя>`.
2. Для каждого артефакта по порядку получи указания `openspec instructions <артефакт> --change <имя>`
   и заполни его: замысел, требования со сценариями, архитектурные решения, план проверки, задачи.
3. Доведи `openspec validate <имя> --strict` до отсутствия ошибок.
Меняй только каталог openspec/. Не делай коммитов - изменения заберут из рабочей копии.
